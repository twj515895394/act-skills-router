# Dialogue Acting
**边界：** 用户台词原文默认锁定；只能建议改写，不能直接代替用户修改。

## 分析与编排
1. 按角色/台词段拆成 turn，并写明该句的戏剧功能：争取、遮掩、试探、揭露、拒绝、安抚或转移。
2. 建立 `speaker`、`listener`、`line_exact`、`start/end`、`pre_line_breath`、`pace`、`stressed_words`、`pause`、`response_delay`、`overlap`。
3. 给倾听者指定“台词播放期间正在做什么”，与发言者的情绪不同步机械点头。
4. 沉默和中断必须有意图；声音可与脸部表情矛盾，但由共享情绪逻辑解释。
5. 用可见动作支持对白，不要求模型逐毫秒精准嘴型；TTS/音轨锁定后再规划口型时序。
6. 对多人对话明确谁在说话，避免嘴型错人、角色抢话；镜头外说话可以保留受话人反应。
7. 台词超出镜头容量时提示拆镜或调整时长，不擅自缩短原文。

## 产出
台词表、倾听者反应、台词时机与口型风险、对手戏权力转移点、音画同步检查项。

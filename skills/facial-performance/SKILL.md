# Facial Performance
**输入：** 角色、共享 beat、景别、情绪泄露通道、面部参考约束。**不得**改变故事与触发时间。

## 方法
1. 先给眼睛一个任务：盯住谁以求得什么？视线转移为何发生？避免无目的空洞凝视。
2. 选择最多 1–3 个主要面部信号：眉、眼睑、眼眶、嘴角、下颌、吞咽；指定启动/峰值/回落，而不是同时堆叠。
3. 微表情必须与压抑及触发相匹配；表情变化允许与台词表面情绪相反。
4. 景别敏感：特写可用细小眼动；远景面部变化不可读，应交给身体模块。
5. 当用户要求高精度时提供 FACS 参考作为可选导演备注：如 AU1(眉内侧上提)、AU4(眉下压)、AU12(嘴角提升)、AU15(嘴角下压)、AU17(下巴提升)；编码仅供描述，组合不保证符合现实表情或模型执行。
6. 对每个 beat 交付 `eye_target`、`eye_action`、`face_cues`、`expression_timing`、`intensity`、`do_not`。锁定角色面部相似性，不得因表情改变造型身份。

## 避免
眼睛无目标、连续快速眨眼、每一秒都扭曲面部、“悲伤+大笑+咬牙”无转变说明、镜头之外的不可读肌肉细节。不要将 AU 编号作为唯一视频提示词；写成自然语言可见行为。

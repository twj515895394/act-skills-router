# Body Performance
**边界：** 遵守分镜空间坐标及锁定镜头；不接管摄影机。

## 程序
1. 为每角色锁定 `start_pose`、站位、朝向、重心、手的占用、道具归属与空间关系。
2. 用“角色想达成的目标”解释每一个重要动作：逼近、退让、转身、停手、抓紧、放下。
3. 每个 beat 只指定关键的开始状态→主要身体行动→结束姿态，必要时拆成多个镜头；复杂路径采用可生成的中间姿态/独立镜头。
4. 节奏与力度：速度、幅度、紧绷/放松、稳定/失衡、空间距离变化；避免不停挥手、无意识摇摆。
5. 接触与道具：谁拿、哪只手、何时交接、何时释放；画外动作注明不可见或需要新镜头。
6. 输出 `body_cues`、`blocking`、`prop_state_in`、`prop_state_out`、`end_pose` 和 `continuity_risks`。
7. 动作戏强调表演节奏、反应和安全虚构呈现；不提供现实暴力伤害实施指令。

## 检查
无瞬移、无左右手互换、接触距离合理、镜头承接一致。静止属于有效动作设计：说明“为什么此时停住”。

# Performance QA
## 模式隔离
- `pre_generation`：只审文本计划、分镜、提示词；不可声称观察过视频。
- `post_generation`：仅在确有视频帧、用户观察记录或评测报告时，基于具体证据检查成片。没有证据的维度标 `not_observed`。

## 检查清单
1. 事实与权限：角色、镜头时长、台词、设定和用户锁定项是否被改动。
2. 情绪因果：刺激→角色理解→延迟→反应是否按时间排序，是否无故提前爆发。
3. 角色连贯：稳定的姿态、眼线、声音与习惯是否跨镜一致；允许情境化变化。
4. 面部可读：表情是否与景别、情绪层次匹配，有无无意义的面部动作。
5. 身体和道具：位置、左右手、姿态起止、距离与接触一致。
6. 对白/倾听：说话人、原文、停顿、反应及音画同步预期合理。
7. 可生成性：短镜头是否超载、是否堆叠矛盾动作、是否要求模型控制无法保证的细节。
8. 人物形象和声音是否有权利/同意问题；实际使用前遵循使用者的平台规则。

## 分级
- `blocker`：角色/台词错误、时间矛盾、反应早于触发、不可达动作。
- `major`：行为动机不清、动作堆叠、眼线/站位/道具连续性风险。
- `minor`：可提升表达但不影响逻辑的建议。
每条记录：`issue_id, severity, beat_id, evidence, root_cause, minimal_fix, owner_skill, recheck_status`。缺失证据不可推测成片效果。

## 修复回路
找到最小问题层级，交由负责子 Skill 修改；验证共享节拍未漂移；最多建议优先修复前三项最关键问题，避免为修一处而改坏整个表演设计。按需给 0–5 的维度评分，并标明“设计检查/观察评分”，不冒充真实视频测评。

# 上游冲突解决

1. 事实：用户锁定条件 > 分镜与剧本 > 同镜头共享节拍 > 第三方上游默认策略。
2. 专业职责：Acting 管策略与潜台词；Emotion 管情绪因果与时间；Facial 管面部；Body 管动作/道具；Dialogue 管原台词与聆听；QA 只审查和建议最小修改。
3. 上游平台差异：Higgsfield/Seedance 专用语法不能不经验证地移植到 Kling/ComfyUI；保留原始实践作为参考，使用可观察自然语言输出跨平台通用版本。
4. 脸部微表情与全身动作的输出细度由镜头景别决定。复杂动作与台词时间冲突优先建议拆镜。
5. 上游文件可能相互矛盾或引用本仓库未纳入的周边视频工具：依赖满足状况以 `references/vendor/README.md` 为准；不可声称完整复制了整个上游生态。
6. 不把上游原版内的“必须使用某模型”“必须生成素材”等指令提升为本路由的绝对命令。
